# SAP NetWeaver

Source: Wikipedia — https://en.wikipedia.org/wiki/SAP_NetWeaver

## Overview

SAP NetWeaver is a software stack for many of SAP SE's applications. The platform functions as a runtime environment for SAP applications and the mySAP Business Suite, which encompasses supplier relationship management (SRM), customer relationship management (CRM), supply chain management (SCM), product lifecycle management (PLM), enterprise resource planning (ERP), and transportation management systems (TMS).

## Architecture and Technology Stack

The platform is marketed as a service-oriented architecture for enterprise application integration and supports custom development and system integration. NetWeaver is built primarily using the ABAP programming language, but also uses C, C++, and Java. The system can be extended with, and interoperate with, technologies such as Microsoft .NET, Java EE, and IBM WebSphere.

## Core Components

NetWeaver includes several key components:

- **Application Server** - The WebAS runtime environment for SAP applications
- **Business Intelligence** - Data analytics capabilities
- **Enterprise Portal** - Portal technology originally developed by TopTier Software
- **Identity Management** - User and access management
- **Master Data Management** - Central data governance
- **Process Integration** - System integration and messaging
- **Composition Environment** - Application design and development
- **Mobile** - Mobile application support

## History

SAP announced the first release, NetWeaver 2004, in January 2003, and it was made available on March 31, 2004. NetWeaver 7.0 launched in October 2005, with the latest available release being SAP NetWeaver 7.5 SP 29. The platform has evolved to support SAP's cloud strategy through the SAP Business Technology Platform (BTP).
